\# legacy-calc-2009



A legacy-style C command-line calculator project (revived from a 2009 starter codebase).



\## Project Setup — Step by Step



1\. Fork the starter repository on GitHub → Name your fork: legacy-calc-2009

2\. Clone your fork locally

3\. Add the `.gitignore` file (already included)

4\. Build the calculator program using `make` or `gcc`

5\. Run the calculator (examples below)
