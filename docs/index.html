LoanCalculator Project Documentation

Small project to calculate loan EMIs (Equated Monthly Installments).

Classes

LoanCalculator

Handles calculation of EMI and total repayment for a loan.

Public Methods

Function Description Parameters Return
LoanCalculator(double amount, double interest, int period) Constructor to initialize loan details.
  • amount: Principal loan amount
  • interest: Interest rate per period (as decimal, e.g., 0.01 for 1%)
  • period: Total number of periods (months)
 None
double calculateEMI() Calculates monthly EMI. None EMI amount as double
double totalRepayment() Calculates total repayment over the loan tenure. None Total repayment amount as double

Tests

Unit tests written using GoogleTest:

  • Normal EMI calculation: Checks EMI calculation for standard loan.
  • Invalid input handling: Ensures zero or negative inputs return 0 or error.
  • Large tenure calculations: Checks EMI calculation for large number of periods without overflow.
